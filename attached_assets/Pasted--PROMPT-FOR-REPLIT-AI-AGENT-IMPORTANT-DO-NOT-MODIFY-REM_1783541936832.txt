
 # PROMPT FOR REPLIT AI AGENT
 
**IMPORTANT: DO NOT MODIFY, REMOVE, REFACTOR, OR BREAK ANY EXISTING FEATURES, PAGES, DATABASES, ROUTES, API ENDPOINTS, EMAIL SYSTEMS, ANALYSIS ENGINE, SMTP SYSTEM, UI, OR BUSINESS LOGIC ON THE HUNTER BOTH THE AUTOMATION. This is an additive feature only. Preserve the existing workflow exactly as it is. Build this as a new extension that plugs into the current system.**
 
## Objective
 
Extend the existing Business Hunter and Website Analysis system by automatically generating a **public client-facing Website Analysis Report** for every completed analysis.
 
The current internal analysis dashboard (used by the agency admin) must remain unchanged.
  
## Existing Workflow (DO NOT CHANGE)
 
Business Search
 
↓
 
Website Analysis
 
↓
 
AI Personalized Email Generation
 
↓
 
Email Sending
 
↓
 
Tracking
 
Everything above must continue working exactly as it currently does.
  
## New Workflow (ADD ONLY)
 
After every successful website analysis:
 
 
1. Save the completed analysis to the database.
 
2. Generate a secure unique Report ID.
 
3. Create a public report page.
 
4. Generate a shareable report URL.
 
5. Automatically inject the report URL into the personalized outreach email.
 
6. Track report views.
 
7. Notify admin whenever a report is opened.
 

  
## Public Report Page
 
Create a new public route:
 
`/report/:reportId`
 
Example:
 
`https://myagency.com/report/8DJ4KPLA`
 
The page must:
 
 
- Be mobile responsive.
 
- Load quickly.
 
- Look professional.
 
- Match the branding of the existing agency.
 
- Require no login.
 
- Display only the report for that Report ID.
 
- Return a 404 page if the report does not exist.
 

  
## Display
 
Populate the report using the existing analysis data already generated by the system.
 
Include:
 
 
- Business Name

- Website Score
 
- Lead Generation Score
 
- Conversion Score
 
- Feature Checklist
 
- Missing Features
 
- Issues Found
 
- Revenue Opportunities
 
- Growth Recommendations
 
- Estimated Project Value
 
- Estimated Delivery Time
 

 
Reuse existing analysis data only.
 
Do NOT create another analysis engine.

Do NOT expose database IDs.
